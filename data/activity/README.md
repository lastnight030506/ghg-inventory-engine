# Simulated manufacturing facility — activity data

A Vietnamese precision-components plant supplying EU automotive and machinery
customers. The numbers are synthetic but internally consistent with a plant of
this size (~3.5 GWh/yr electricity, one diesel-fired furnace line, one coal-fired
boiler, inbound steel freight). Replace with metered data before any real filing.

| Source | What it is |
|---|---|
| `grid_electricity` | Purchased electricity, metered monthly, Scope 2 |
| `diesel_furnace` | Diesel burned in the heat-treatment furnace, Scope 1 |
| `coal_boiler` | Bituminous coal in the steam boiler, Scope 1 |
| `inbound_freight_road` | Truck tonne-km bringing steel coil from Hai Phong port, Scope 3 cat. 4 |
| `inbound_freight_sea` | Sea freight tonne-km from Busan, Scope 3 cat. 4 |
